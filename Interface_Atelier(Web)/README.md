# Projet web : interface « Atelier »

Ce dossier accueillera l’interface « Atelier » de T.G.V, utilisée sur les PC de l’atelier :

- gestion des clients (ajout, modification, suppression) ;
- gestion des commandes (pièce, client, poids, date prévue) ;
- modification de l’état des pièces (à faire, en cours de fabrication, fabriquée, livrée) ;
- suivi des colis livrés (bons de livraison) ;
- consultation des boucles de livraison (trajet et kilomètres parcourus).

La maquette de référence se trouve dans `../Maquettes` (vue « Atelier »).
L’application Android du chauffeur se trouve dans `../android`.
